## 현재 개발 단계

v0.3.4 계열은 아트와 본격적인 사운드 작업 전, 메타 흐름·캐릭터 영구 성장·전투 회귀를 확정하는 단계입니다.

v0.3.4.h 기준 완료 사항:

1. 타이틀 화면의 큰 프레임과 설명을 제거하고 아트 배경 위 제목·시작·설정만 유지
2. 타이틀 → 캐릭터 선택 → 준비 화면 → 챕터 선택 → 병동 진입 흐름 적용
3. 챕터 1 정식 표기를 `CHAPTER I β`, 부제를 `비어 있는 자리`로 수정
4. 베타의 다무기 수용, 잔존자의 피해 유예, 당직자의 위험 대상 분류를 모든 무기에 적용되는 캐릭터 규칙으로 재설계
5. 각 캐릭터의 개인능력을 0강 기본 규칙과 1~10강 영구 강화로 확장
6. 강화 비용을 100~2,600 검체 규모로 확대하고 기존 보유 검체를 100배 단위로 자동 이전
7. 검체 획득량을 확대하고 미니맵 아래에 현재 런 회수량을 상시 표시
8. 검체 획득 토스트를 제거하고 숫자 반응만 유지
9. 봉합사 2박 군집 구조와 절개선 정확 선분 충돌 판정을 재통합
10. v0.3.4.g의 맵 경계 카메라 처리를 유지
