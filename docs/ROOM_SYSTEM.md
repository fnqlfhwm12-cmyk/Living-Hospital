# 방 시스템 기준

마지막 갱신: 2026-08-02

이 문서는 Living Hospital의 방을 세부 설계할 때 공통으로 지켜야 할 생성·전투·상태 규칙을 정리합니다.

## 핵심 방향

> 층은 방을 만든 뒤 적을 계속 뿌리는 공간이 아니라, 도착 순간 이미 배치가 완성된 전투 구역입니다.

엔터 더 건전처럼 각 방은 독립된 전투 상황을 가집니다. 적 종류와 수만 무작위로 뿌리지 않고, 방의 출입구·장애물·적 위치를 한 묶음의 인카운터로 취급합니다.

## 층 생성 순서

1. 층의 방 연결 구조 결정
2. 방별 기능 결정
3. 방 템플릿과 장애물 배치 결정
4. 전투방별 인카운터 템플릿 추첨
5. 적 종류·수·정확한 좌표를 내부 로그에 기록
6. 적을 해당 좌표에 대기 상태로 배치
7. 플레이어가 층에 진입

같은 런에서 방을 나갔다 돌아오거나 일시정지해도 배치가 다시 추첨되지 않습니다.

## 대기 상태

- 적은 플레이어가 방에 들어오기 전부터 정해진 위치에 존재합니다.
- 대기 중에는 이동, 추적, 경로 탐색, 공격과 접촉 피해를 수행하지 않습니다.
- 대기 적은 다른 방으로 빠져나오거나 거리 때문에 자동 삭제되지 않습니다.
- 플레이어가 문밖에서 공격하더라도 대기 적은 전투 시작 전까지 피해를 받지 않습니다.
- 문이나 시야를 통해 적의 일부가 미리 보일 수 있습니다.

## 전투 시작

- 플레이어 중심이 방 경계 안쪽의 안전 거리까지 들어오면 인카운터를 시작합니다.
- 모든 출입구가 물리적으로 봉쇄됩니다.
- 해당 방에 배정된 적의 대기 상태가 동시에 해제됩니다.
- 별도의 전투 시작 문구, 방 이름과 목표 텍스트를 표시하지 않습니다.
- 문 폐쇄음, 적의 자세 변화, 조명과 음향 전환으로 시작을 전달합니다.

## 전투 종료

- 해당 방에 배정된 적이 모두 제거되면 클리어됩니다.
- 출입구 봉쇄물이 제거됩니다.
- 검체는 자동 회수됩니다.
- 방에 연결된 보상이 활성화될 수 있습니다.
- 재방문 시 적이 다시 생성되지 않습니다.
- 시간 경과로 추가 웨이브가 발생하지 않습니다.

특정 방이 추가 증원이나 재생을 사용한다면 일반 규칙이 아니라 그 방만의 명시적인 특수 기믹으로 설계합니다.

## 현재 기본 적

방 구조와 배치의 재미를 먼저 검증하기 위해 모든 일반 적을 기본 환자형 하나로 통일합니다.

현재 검증 대상:

- 플레이어를 향한 기본 추적
- 근접 접촉 공격
- 벽과 장애물 우회
- 적끼리의 최소한의 밀집 해소
- 넉백과 상태이상 반응

새로운 적 유형은 기본 섬멸방 템플릿이 안정된 이후 추가합니다.

## 인카운터 템플릿

인카운터 템플릿은 다음 요소를 한 묶음으로 가집니다.

- 사용 가능한 방 형태
- 허용 출입구 방향
- 장애물 배치
- 적 좌표 목록
- 적이 바라보는 방향 또는 자세
- 전투 시작 시 활성화 순서
- 클리어 조건
- 연결 보상 여부

현재 v0.4.0.c는 기본 환자형 적의 좌표 패턴만 적용한 기술 기준선입니다. 실제 섬멸방 설계에서는 적 좌표를 방 구조와 장애물에 맞춰 수작업 템플릿으로 교체합니다.

## 랜덤성

- 어떤 인카운터 템플릿이 어느 전투방에 들어가는지는 무작위로 정할 수 있습니다.
- 템플릿이 선택된 뒤 내부 적 좌표를 다시 매초 무작위화하지 않습니다.
- 같은 템플릿도 좌우 반전, 상하 반전과 진입 방향 변환을 사용할 수 있습니다.
- 적이 장애물 또는 문과 겹치는 배치는 생성 단계에서 제외합니다.
- 플레이어 시작 위치와 적 사이의 최소 안전 거리를 보장합니다.

## 인게임 정보 전달

- 플레이 화면에는 방 이름, 섬멸 목표와 남은 적 수를 글자로 표시하지 않습니다.
- 닫힌 문은 방이 진행 중임을 나타냅니다.
- 적대음이 사라지고 문이 열리는 것으로 완료를 알립니다.
- 마지막 적을 찾기 어렵다면 미니맵 글자 대신 방 안의 방향성 맥박, 바닥 파동 또는 음향으로 위치를 암시합니다.

## 성능 원칙

- 층 생성 시 모든 인카운터의 데이터는 미리 확정합니다.
- 실제 AI와 경로 탐색은 활성화된 현재 방의 적에게만 적용합니다.
- 미진입 방의 적은 좌표와 최소 상태만 유지합니다.
- 대기 적 때문에 프레임 루프의 경로 탐색과 충돌 검사가 증가하지 않아야 합니다.
- 방을 클리어하면 해당 적 객체와 전투용 임시 객체를 즉시 정리합니다.

## 현재 다음 단계

섬멸방을 다음 순서로 세밀하게 설계합니다.

1. 기본 방 크기와 화면 점유율
2. 출입구 수와 진입 방향
3. 장애물 종류와 충돌 범위
4. 플레이어 진입 안전 구역
5. 기본 환자형 적의 수와 대기 좌표
6. 적 활성화 순간의 문·조명·사운드
7. 마지막 적 처치와 문 개방 반응
8. 반복 가능한 섬멸방 템플릿 수
