# 개발 로드맵

로드맵은 순서를 정하기 위한 문서이며, 세부 수치와 실제 버전은 플레이 테스트 결과에 따라 조정합니다.

## 1. v0.3.3 안정화

- [ ] 심장박동 추가타·치명타 구조 정리
- [ ] 무기별 단일·광역 역할과 피해 효율 재검토
- [ ] 자가포식 웅덩이의 지속 피해, 슬로우, 저지력 완성
- [ ] 적 이동속도와 벽 충돌 문제 안정화
- [ ] 맵 아이템의 전 구간 랜덤 생성 확인
- [ ] 상호작용 버튼 및 잔존 UI 오류 정리
- [ ] iPhone 발열·프레임 저하 점검

## 2. v0.3.4 신규 콘텐츠

안정화가 끝난 뒤 진행합니다.

- [ ] 기본 무기군 확장
- [ ] 패시브 체감 강화와 역할 분리
- [ ] 장기 6종의 개성 및 교체 안정성 완성
- [ ] 병동 구성과 매 판 활성 구조 정리
- [ ] 보스 및 유물 기믹의 기반 설계

## 3. 전투 성장 구조 완성

- [ ] 무기 진화 레시피
- [ ] 진화 등장 확률과 조건
- [ ] 각성 단계
- [ ] 캐릭터별 기본 무기 차별화
- [ ] 30~45분 전체 난이도 곡선

## 4. 콘텐츠와 서사

- [ ] 실험체 캐릭터 설정
- [ ] 병동·실험실 세력 구조
- [ ] 순차 보스와 기믹 아이템
- [ ] 비밀 루트 장기와 조건
- [ ] 최소 텍스트 기반 환경 서사

## 지속 과제

아래 항목은 모든 버전에서 함께 확인합니다.

- 성능과 발열
- 타격 판독성
- 화면 과밀도
- 모바일 조작감
- 이전 장기·무기 효과 잔존 버그
- 게임이 너무 빠르게 자동화되지 않는지 여부
