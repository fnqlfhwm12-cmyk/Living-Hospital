## v0.4.0.c 구조 기준선

1. 다른 플레이어블 캐릭터를 제거하고 베타만 남김
2. 캐릭터 개인능력과 1~10강 효과·표시 비활성화
3. 무기는 최대 2개이며 활성 무기 하나만 공격
4. 대기 무기의 공통 보조효과 제거
5. 바닥 무기 근처에서 같은 상호작용 버튼으로 활성 무기와 즉시 맞교환
6. 빈 무기 슬롯이 있으면 기존 무기가 대기 슬롯으로 이동하고 새 무기가 활성화
7. 방 이름, 토스트, 설명용 전투 UI 글자 제거
8. F1의 장기·유물 보상 노드 제거
9. 현재 일반 적을 기본 환자형 하나로 통일
10. 층 생성 시 전투방마다 적 수와 정확한 위치를 내부 인카운터 로그에 미리 배정
11. 방에 들어가기 전 적은 지정 위치에서 대기하고 추적·경로 탐색을 하지 않음
12. 전투방 안쪽 진입 시 출입구 봉쇄와 적 활성화
13. 해당 방의 적을 모두 처치하면 출입구 재개방
14. 시간 경과에 따라 화면 밖에서 적이 생성되는 기본 웨이브 구조 중단
15. 재방문한 클리어 방은 적이 다시 생성되지 않음

## 현재 유지되는 기존 기반

- 하트 3개, 총 6칸 체력과 유효 피격당 반 칸 감소
- 이동 손가락을 유지한 상태의 상호작용 버튼 입력
- 장기·유물·무기·검체 중심의 컴팩트 HUD
- 미방문 방의 어두운 미니맵 실루엣
- 적 처치 검체 자동 회수
- 현재 방 중심의 오브젝트·충돌 계산 기반

## 서사 설계 완료 범위

### 세계관

- 미래형 병원과 오메가의 연결, 점진적 잠식, 연결 해제 시도와 폭주
- 오메가의 목적을 죽음 없는 재생 체계의 외부 확장으로 정리
- 모든 주요 인물과 세력을 오메가에서 파생된 독립 부산물로 통일
- 베타를 고정 성격이 아닌 플레이어 행동의 주체로 확정
- 반복 플레이를 베타의 재생과 일부 사건 기억으로 해석

문서: `docs/NARRATIVE_CORE.md`

### 타우와 누

- 타우가 F2에서 장기 시스템을 영구 해금
- 누가 중반 첫 접촉에서 유물 시스템을 영구 해금
- 누의 체제를 미래형 의료 복지와 종교적·오컬트적 임상 의식의 결합으로 확장
- 두 인물은 플레이어블 캐릭터가 아니라 반복 등장하는 NPC·보스·세력 지도자로 유지

## v0.4.0.c 플레이 확인 항목

- 첫 바닥 무기 획득 시 기존 무기가 대기 슬롯으로 이동하는지
- 무기 두 개 보유 중 바닥 무기를 주우면 활성 무기만 바닥에 남는지
- 바닥 무기에서 떨어지면 버튼이 정상적인 무기 전환 기능으로 돌아오는지
- 대기 무기가 자동 공격하거나 공통 보조효과를 내지 않는지
- 전투방에 들어가기 전 적이 지정 위치에서 움직이지 않는지
- 다른 방의 대기 적이 사라지거나 플레이어를 추적하지 않는지
- 방 안쪽 진입 시 모든 출입구가 막히는지
- 해당 방의 적을 모두 처치하면 출입구가 다시 열리는지
- 클리어 방에 재진입해도 적이 재생성되지 않는지
- 전투 화면에 방 이름, 획득·교체 설명과 토스트가 나타나지 않는지
- iPhone에서 대기 적 2개 방을 미리 보유해도 프레임과 발열이 안정적인지
