# 변경 기록

모든 주요 게임 코드 변경은 버전 파일과 함께 이 문서에 기록합니다.

## 작업 중

- 다음 게임 버전 후보: `v0.3.4.i`
- 작업 시작 시 최신 저장소 상태를 확인한 뒤 버전 확정
- 변경 전 핵심 수치와 변경 후 결과를 함께 기록

### 2026-07-30 개발 인프라

게임 빌드 버전은 변경하지 않고 저장소 운영과 플레이테스트 기반을 추가했습니다.

- `playtest.html` 계측 플레이 페이지 추가
- 평균·최저·최근 FPS 근사값 기록
- Long Task, 터치 입력, 화면 방향·가시성 변경 기록
- JavaScript 오류와 처리되지 않은 Promise 오류 수집
- 게임 타이머와 `#debug` 표시 내용 보고서 포함
- 보고서 복사 및 iOS 공유 메뉴 지원
- 계측값 자동 외부 전송 없음
- `.github/workflows/validate.yml` GitHub Actions 추가
- `scripts/validate_repo.mjs` 정적 검사기 추가
- 최신 빌드와 문서·실행 주소 참조 일치 검사
- HTML 기본 구조, 인라인 JavaScript 문법, 중복 `id`, 병합 충돌 표시 검사
- 플레이테스트 운영 문서와 저장소 작업 규칙 갱신

## v0.3.3.u

전투 밸런스는 v0.3.3.t 기준을 유지하고 플레이테스트 자동 계측을 게임 본체에 연결했습니다.

- 플레이 종료 시 게임 내부 스냅샷 생성
- 계측 페이지에서 종료 보고서 자동 표시
- JavaScript 오류와 처리되지 않은 Promise 오류 자동 기록
- 500ms 이상 프레임 정지와 250ms 이상 프레임 지연 감지
- 지속 저프레임, 적 정체, 개체 수 상한 초과 감지
- 플레이 시간, 처치 수, FPS, 프레임 지연, 개체 수, HP, 위치, 장기·무기·패시브 구성 기록
- 경고는 백그라운드 기록, 치명·심각 오류는 보고서 자동 표시
- 수동 기록 버튼은 비상용으로 축소
- 계측 정보 자동 외부 전송 없음
