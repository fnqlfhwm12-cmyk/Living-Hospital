# 프로젝트 상태

마지막 갱신: 2026-08-02

## 현재 기준

- 저장소 기준 최신 빌드: **v0.4.0.a**
- 기준 파일: `Living_Hospital_v0.4.0.a.html`
- 작업 브랜치: `agent/v035-structural-prototype`
- 주 테스트 환경: iPhone 가로 화면

## 현재 개발 단계

v0.4.0.a는 기존 v0.3.4.h 전투 엔진을 유지하면서 게임의 큰 진행 구조를 교체한 1차 프로토타입입니다.

적용된 골격:

1. 단일 대형 병실을 일곱 개 방과 짧은 통로로 구성된 층으로 교체
2. EXP 바와 레벨업 선택을 제거하고 적 처치 보상을 검체로 전환
3. 무기 보유량을 주무기 1개와 보조무기 1개로 제한
4. A버튼으로 두 무기의 역할을 교체하고, 대기 무기는 보조효과 제공
5. 패시브는 중복 없이 누적되며 화면상 레벨 제거
6. 장기 1개 교체식 구조 유지
7. 유물 최대 3개 보유 골격 추가
8. 방 보상 세 개를 회수하면 다음 층으로 이동 가능
9. 오메가가 병원을 장악해 내부를 변형한다는 서사 전제로 변경

## 이번 버전의 의도적 한계

- 방 배치는 아직 고정형입니다.
- 무기별 보조효과와 유물 효과는 구조 검증용 1차 수치입니다.
- 장기 목표군 6종 중 기존 구현된 심장·뇌·위만 실제 작동합니다.
- 봉쇄문, 방별 세부 목표, 무기·패시브 시너지 태그는 다음 단계입니다.
- 보스 타임라인은 구조 검증 중 임시 비활성화했습니다.

## 우선 확인 항목

- 방과 통로에서 적이 벽에 장시간 걸리지 않는지
- A버튼 스왑이 기존 상호작용과 충돌하지 않는지
- 주무기만 완전 공격하고 보조무기는 직접 동시 발사하지 않는지
- 보상 세 개 회수 후 층 이동이 정상 작동하는지
- iPhone 가로 화면에서 새 HUD가 겹치거나 잘리지 않는지
- EXP 제거 후 검체 획득량과 전투 동기가 적절한지
