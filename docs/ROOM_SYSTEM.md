# 방 시스템 기준

마지막 갱신: 2026-08-04

이 문서는 Living Hospital의 방을 세부 설계할 때 공통으로 지켜야 할 생성·전투·상태 규칙을 정리합니다.

## 핵심 방향

> 층은 방을 만든 뒤 적을 계속 뿌리는 공간이 아니라, 도착 순간 이미 배치가 완성된 전투 구역입니다.

엔터 더 건전처럼 각 방은 독립된 전투 상황을 가집니다. 적 종류와 수만 무작위로 뿌리지 않고, 방의 출입구·장애물·적 위치를 한 묶음의 인카운터로 취급합니다.

## 층 생성 순서

1. 층의 방 연결 구조 결정
2. 방별 기능 결정
3. 방 템플릿과 장애물 배치 결정
4. 전투방별 인카운터 템플릿 추첨
5. 적 종류·수·정확한 좌표를 내부 로그에 기록
6. 적을 해당 좌표에 대기 상태로 배치
7. 플레이어가 층에 진입

같은 런에서 방을 나갔다 돌아오거나 일시정지해도 배치가 다시 추첨되지 않습니다.

## 미로형 층 규칙

- 한 층은 현재 9~10개 방으로 생성합니다.
- 시작방은 층의 최남단에 고정합니다.
- 시작방에는 북쪽 출구 하나만 둡니다.
- 이후 방은 층 생성 결과에 따라 동·서·남·북으로 연결합니다.
- 플레이어가 들어온 문도 전투 종료 후 다시 열리므로 이전 방으로 돌아갈 수 있습니다.
- 막다른 길, 분기와 소수의 순환 연결을 함께 생성합니다.
- 시작방에서 가장 먼 방을 층 출구로 지정합니다.
- 모든 방과 층 출구는 반드시 도달 가능해야 합니다.
- 출입구는 방 진입 시 새로 추첨하지 않고 층 생성 순간 고정합니다.

## 대기 상태

- 적은 플레이어가 방에 들어오기 전부터 정해진 위치에 존재합니다.
- 대기 중에는 이동, 추적, 경로 탐색, 공격과 접촉 피해를 수행하지 않습니다.
- 대기 적은 다른 방으로 빠져나오거나 거리 때문에 자동 삭제되지 않습니다.
- 플레이어가 문밖에서 공격하더라도 대기 적은 전투 시작 전까지 피해를 받지 않습니다.
- 문이나 시야를 통해 적의 일부가 미리 보일 수 있습니다.

## 전투 시작

- 플레이어 중심이 방 경계 안쪽의 안전 거리까지 들어오면 인카운터를 시작합니다.
- v0.4.0.d의 진입 안전 거리는 방 경계에서 안쪽으로 150px입니다.
- 모든 연결 출입구가 물리적으로 봉쇄됩니다.
- 해당 방에 배정된 적의 대기 상태가 해제됩니다.
- 별도의 전투 시작 문구, 방 이름과 목표 텍스트를 표시하지 않습니다.
- 문 폐쇄음, 적의 자세 변화, 조명과 음향 전환으로 시작을 전달합니다.

## 전투 종료

- 해당 방에 배정된 적이 모두 제거되면 클리어됩니다.
- 출입구 봉쇄물이 제거됩니다.
- 검체는 자동 회수됩니다.
- 방에 연결된 보상이 활성화될 수 있습니다.
- 재방문 시 적이 다시 생성되지 않습니다.
- 시간 경과로 일반 추가 웨이브가 발생하지 않습니다.

특정 방이 추가 증원이나 재생을 사용한다면 일반 규칙이 아니라 그 방만의 명시적인 특수 기믹으로 설계합니다. 현재 배양 중 변질도 새로운 적을 생성하는 것이 아니라, 층 생성 시 이미 배정된 적의 대기 상태를 순차적으로 해제합니다.

## 현재 기본 적

방 구조와 배치의 재미를 먼저 검증하기 위해 모든 일반 적을 기본 환자형 하나로 통일합니다.

현재 검증 대상:

- 플레이어를 향한 기본 추적
- 근접 접촉 공격
- 벽과 장애물 우회
- 적끼리의 최소한의 밀집 해소
- 넉백과 상태이상 반응

새로운 적 유형은 기본 섬멸방 템플릿이 안정된 이후 층별 적군으로 확장합니다.

# 섬멸방

섬멸방은 현재 구현된 첫 번째 상위 방 유형입니다.

## 기본 규격

- 기본 크기: 1020×720
- 목표 체감: 방 끝에서 반대편 끝까지 직선 이동 약 6초
- 클리어 동사: 전멸
- 적 수와 좌표: 층 생성 시 확정
- 출입구: 미로 연결 방향을 그대로 사용
- 전투 중 모든 연결문 봉쇄
- 전멸 후 모든 연결문 재개방

실제 이동 시간은 현재 이동속도와 장애물에 따라 달라질 수 있으므로 iPhone 플레이테스트에서 최종 조정합니다.

## 공간형

공간형은 방의 장애물과 전투 동선을 결정합니다. 공간형 자체가 반드시 희귀 기믹을 뜻하지는 않습니다.

### 일반 공간형

- 기본형
- 병상형
- 검사장비형
- 격리형
- 개방형
- 창고형

### 희귀 공간형

- 붕괴형
- 수술형
- 배양형

## 변질 상태

공간형과 별도로 낮은 확률로 방의 분위기 또는 전투 규칙을 바꿉니다.

### 경미한 변질

조작 규칙을 크게 바꾸지 않고 분위기와 동선 인지만 변화시킵니다.

- 정전
- 생체화
- 얕은 침수

경미한 변질 출현 확률:

| 층 | 확률 |
|---|---:|
| F1 | 8% |
| F2 | 10% |
| F3 | 12% |
| F4 | 14% |
| F5 | 16% |
| F6 | 18% |
| F7 | 20% |

- 층당 최대 1개
- 같은 층의 모든 방에 독립적으로 확률을 굴리지 않음
- 층 생성 시 존재 여부를 한 번 판정한 뒤 방 하나에만 배정

### 강한 희귀 변질

실제 전투 판단을 바꿉니다.

- 오염: 위험 웅덩이가 플레이어와 적 모두에게 작용
- 멸균: 예고된 소독광이 플레이어와 적을 타격
- 압착: 주기적으로 방 외곽의 안전 면적이 감소
- 배양 중: 미리 배정된 적이 일정 간격으로 대기 상태에서 해제

희귀 섬멸방 출현 확률:

| 층 | 확률 |
|---|---:|
| F1 | 0% |
| F2 | 3% |
| F3 | 4% |
| F4 | 5% |
| F5 | 6% |
| F6 | 7% |
| F7 | 8% |

- 층당 최대 1개
- 경미한 변질과 같은 방에 중첩하지 않음
- 첫 섬멸방을 강한 희귀 변질로 만들지 않는 방향을 우선 검토

## 상황 배치

상황 배치는 플레이어가 들어오기 전 방에서 어떤 일이 벌어지고 있었는지 보여줍니다. 클리어 조건은 여전히 전멸입니다.

- 수술 중
- 회수 중
- 청소 중
- 재생 중
- 격리 해제 직전

적이 새로 생성되는 연출보다 자세, 배치와 순차 활성화로 상황을 표현합니다.

# 버그방

버그방은 일반 희귀 변질과 별도로 판정하는 극희귀 섬멸방입니다.

## 생성 규칙

- 일반 런당 존재 확률: 1%
- 한 런 최대 1개
- F3~F6에서만 생성
- 가능한 경우 막다른 선택 분기에 배치
- 필수 진행, 보스, 서사와 시스템 해금 방을 대체하지 않음
- 개발 테스트에서는 `?bugroom=1`로 F1 강제 생성 가능

방마다 1%를 판정하지 않습니다. 런 시작 시 버그방 존재 여부와 대상 층을 한 번 결정합니다.

## 전투 규칙

- 기본 환자형 체력 ×1.7
- 피해 ×1.5
- 이동속도 ×1.12
- 판독 가능한 피격 범위와 공격 경고는 유지
- 깨진 그래픽은 시각 연출에만 적용하고 실제 충돌과 조작을 깨뜨리지 않음

## 오류 아이템

버그방을 클리어하면 전용 풀에서 오류 아이템 하나를 획득합니다.

- 누락된 피해
- 넘친 시계
- 중복 회수
- 기록되지 않은 죽음
- 잘못된 참조

오류 아이템은 해당 런에서만 작동하며 일반 유물 3칸을 점유하지 않습니다. 일반 아이템 풀, 필수 해금과 엔딩 조건에는 포함하지 않습니다.

## 인카운터 템플릿

인카운터 템플릿은 다음 요소를 한 묶음으로 가집니다.

- 사용 가능한 방 형태
- 실제 출입구 방향
- 장애물 배치
- 적 좌표 목록
- 적이 바라보는 방향 또는 자세
- 전투 시작 시 활성화 순서
- 클리어 조건
- 연결 보상 여부
- 공간형, 변질과 상황 배치

같은 템플릿은 회전과 반전을 사용할 수 있지만 문, 장애물과 적 좌표가 함께 변환되어야 합니다.

## 인게임 정보 전달

- 플레이 화면에는 방 이름, 섬멸 목표와 남은 적 수를 글자로 표시하지 않습니다.
- 닫힌 문은 방이 진행 중임을 나타냅니다.
- 적대음이 사라지고 문이 열리는 것으로 완료를 알립니다.
- 위험 기믹은 바닥, 조명, 소리와 움직임으로 실제 판정 전에 예고합니다.
- 마지막 적을 찾기 어렵다면 방향성 맥박, 바닥 파동 또는 음향으로 위치를 암시합니다.
- 버그방은 문과 미니맵 외곽선의 깨짐으로 진입 전 위험을 암시합니다.

## 성능 원칙

- 층 생성 시 모든 인카운터 데이터를 미리 확정합니다.
- 실제 AI와 경로 탐색은 활성화된 현재 방의 적에게만 적용합니다.
- 미진입 방의 적은 좌표와 최소 상태만 유지합니다.
- 대기 적 때문에 프레임 루프의 경로 탐색과 충돌 검사가 증가하지 않아야 합니다.
- 방을 클리어하면 해당 적 객체와 전투용 임시 객체를 정리합니다.
- 깨진 그래픽은 제한된 사각형·잔상 연출로 구현하고 고비용 후처리를 사용하지 않습니다.

## 다음 단계

현재 구현은 전체 방 유형 중 섬멸방에만 해당합니다. 다음에는 목표 전투방, 무기방, 적응방, 사건방 등 다른 상위 방 유형을 설계한 뒤 공통 생성·진입·클리어 인터페이스에 추가합니다.
