# 프로젝트 상태

마지막 갱신: 2026-08-04

## 현재 기준

- 저장소 기준 최신 빌드: **v0.4.0.d**
- 기준 파일: `Living_Hospital_v0.4.0.d.html`
- 주 테스트 환경: iPhone 가로 화면
- 표면 병원 구조: **7층**
- 플레이어블 캐릭터: **베타 단일**
- 현재 구현한 상위 방 유형: **섬멸방**

## v0.4.0.d 구현 범위

### 미로형 층 생성

1. 한 층을 9~10개 방으로 무작위 생성
2. 시작방을 최남단에 고정하고 북쪽 출구 하나만 연결
3. 이후 방은 실제 미로 연결에 따라 동·서·남·북 출입구를 가짐
4. 시작방에서 가장 먼 방을 층 출구로 지정
5. 막다른 길, 분기와 소수의 순환 연결을 함께 생성
6. 미방문 방은 미니맵에서 어두운 실루엣으로 유지

### 섬멸방 공통 규칙

1. 기본 방 크기를 1020×720으로 설정
2. 층 생성 시 방별 적 수와 정확한 대기 좌표를 확정
3. 현재 일반 적은 기본 환자형 하나로 통일
4. 플레이어가 방 경계에서 150px 안쪽까지 들어오면 출입구 봉쇄
5. 방에 배정된 적만 활성화하고 전멸 시 모든 출입구 재개방
6. 클리어한 방은 재방문해도 적을 다시 생성하지 않음
7. 시간 경과에 따라 화면 밖에서 적이 몰려오는 일반 웨이브는 사용하지 않음

### 섬멸방 내부 유형

- 일반 공간형 6종: 기본형, 병상형, 검사장비형, 격리형, 개방형, 창고형
- 희귀 공간형 3종: 붕괴형, 수술형, 배양형
- 경미한 변질 3종: 정전, 생체화, 얕은 침수
- 강한 변질 4종: 오염, 멸균, 압착, 배양 중
- 상황 배치 5종: 수술 중, 회수 중, 청소 중, 재생 중, 격리 해제 직전

### 출현 제한

- 경미한 변질은 층당 최대 1개
- 경미한 변질 확률은 F1 8%에서 F7 20%까지 증가
- 희귀 섬멸방은 층당 최대 1개
- 희귀 섬멸방 확률은 F1 0%, F2 3%에서 F7 8%까지 증가
- 경미한 변질과 희귀 섬멸방은 같은 방에 중첩하지 않음

### 버그방

- 일반 런에서 존재할 확률 1%
- 한 런 최대 1개
- F3~F6에서만 생성
- 가능한 경우 막다른 선택 분기에 배치
- 깨진 그래픽 연출과 강화된 기본 환자형 적용
- 버그 적: 체력 ×1.7, 피해 ×1.5, 이동속도 ×1.12
- 클리어 시 오류 아이템 5종 중 하나를 획득
- 개발 테스트에서는 주소 뒤에 `?bugroom=1`을 붙여 F1에 강제 생성 가능

오류 아이템:

- 누락된 피해
- 넘친 시계
- 중복 회수
- 기록되지 않은 죽음
- 잘못된 참조

## 현재 유지되는 기반

- 베타 단일 플레이어블
- 하트 3개, 총 6칸 체력
- 무기 최대 2개와 활성 무기 단독 공격
- 바닥 무기와 활성 무기의 즉시 맞교환
- 패시브 무제한 비중복 누적
- 메인 장기 1개, 유물 최대 3개 골격
- 적 처치 검체 자동 회수
- 플레이 화면의 방 이름·목표·획득 설명 제거
- 현재 방 중심의 AI·충돌 연산

## 아직 구현하지 않은 상위 방 유형

이번 버전은 전체 방 유형 중 **섬멸방만 구현**했습니다.

- 목표 전투방
- 독립 무기방
- 적응·패시브방
- 이식방
- 유물방
- 회복·자원방
- 사건방
- 서사방
- 보스방
- 비밀방
- 층 이동방의 최종 연출

해당 방들은 세부 설계를 확정한 뒤 공통 방 인터페이스에 추가합니다.

## 다음 플레이 확인 항목

- 시작방이 항상 최남단이며 북쪽 문 하나만 가지는지
- 모든 방과 출구가 실제로 도달 가능한지
- 방 끝에서 끝까지 이동 체감이 약 6초에 가까운지
- 출입구 방향과 장애물이 겹치지 않는지
- 150px 진입 안전 구역이 너무 짧거나 길지 않은지
- 미진입 방의 적이 움직이거나 피해받지 않는지
- 전멸 후 모든 연결문이 안정적으로 다시 열리는지
- 공간형 9종이 실제 전투 동선을 구분하는지
- 경미한 변질이 피로를 만들지 않고 분위기만 바꾸는지
- 강한 변질의 시각 예고와 실제 판정이 일치하는지
- 버그방 연출이 공격 판독성과 조작을 방해하지 않는지
- 오류 아이템이 일반 유물 3칸을 점유하지 않는지
- iPhone 가로 화면의 프레임, 발열과 터치 입력이 안정적인지

자동 정적 검사는 통과했지만 실제 iPhone 조작감과 성능은 수동 플레이테스트가 필요합니다.
