## 현재 개발 단계

v0.3.4 계열은 챕터 1 전투 구조, 캐릭터 기본 무기, 단일 병실 맵과 모바일 성능을 함께 정리하는 단계입니다.

v0.3.4.f 기준 완료 사항:

1. 봉합사를 첫 타 군집 꿰기, 다음 타 군집 봉합 구조로 리워크
2. 봉합사 1레벨 4명, 8레벨 8명 대상 및 치명타 두 군집 구조 적용
3. 절개선의 시각 선분과 적·오브젝트 충돌 판정을 동일한 폭으로 통일
4. 병실 플레이 영역을 4600×2800으로 확장하고 시각 바닥을 5840×3800으로 연장
5. 충돌 외벽은 유지하되 화면에서는 숨겨 갇힌 느낌 완화
6. 일반 적·웨이브·이벤트 생성 위치를 현재 카메라 시야 밖으로 보정
7. 보스 본체와 보스 직접 배출 적만 의도된 화면 내 생성 예외로 유지

## 다음 작업 후보

다음 버전 후보는 **v0.3.4.g**입니다. 실제 작업 시작 시 저장소의 최신 상태를 확인한 뒤 확정합니다.

우선 검토:

- iPhone 가로 화면에서 봉합사 1타·2타 리듬과 군집 연결선 판독성 확인
- 치명타 두 군집이 가까운 적 밀집 상황에서도 분리되어 보이는지 확인
- 절개선이 선 밖 오브젝트를 때리지 않고 모든 지정 파괴 대상을 정상 타격하는지 실기기 확인
- 맵 외곽 접근 시 숨겨진 충돌 경계가 부자연스럽게 느껴지지 않는지 확인
- 적 생성이 시야 밖이더라도 지나치게 멀거나 특정 방향에 편중되지 않는지 확인
- 확장된 맵에서 초반 이동 밀도와 전투 공백이 과도하지 않은지 확인
- 계측 플레이 보고서로 변경 전후 FPS, 최대 적 수, 오류 비교
