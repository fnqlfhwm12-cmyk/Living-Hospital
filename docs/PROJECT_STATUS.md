## 현재 게임 빌드 상태

1. A버튼을 이동 조작과 동시에 누를 수 있도록 터치 시작 시점에 스왑 처리
2. 좌측 상단 HUD를 하트 체력, 장기·유물, 무기 두 칸, 검체 순서로 재배치
3. 체력을 하트 3개, 총 6칸으로 변경하고 유효 피격당 반 칸 감소
4. 진행 시간과 화면 디버그 문구 숨김
5. 방문하지 않은 방은 미니맵에서 어두운 실루엣으로만 표시
6. 적 처치 검체는 구슬을 생성하지 않고 자동 회수
7. 검체 보관실 보상도 방 진입 시 자동 회수되어 필드 오브젝트를 남기지 않음

## 서사 설계 완료 범위

### 1. 세계관 핵심 규칙

- 미래형 병원과 오메가의 연결, 점진적 잠식, 연결 해제 시도와 폭주 확정
- 오메가의 목적을 죽음 없는 재생 체계의 외부 확장으로 정리
- 모든 주요 인물과 세력을 오메가에서 파생된 독립 부산물로 통일
- 베타를 고정 성격이 아닌 플레이어 행동의 주체로 확정
- 반복 플레이를 베타의 재생과 일부 사건 기억으로 해석

문서: `docs/NARRATIVE_CORE.md`

### 2. 타우와 누

- 타우를 장기 시스템 해금과 탈출 서사의 중심으로 정리
- 타우가 동행하지 않고 흔적과 재등장으로 서사를 이끄는 방식 확정
- 누를 실제로 고통을 줄였지만 그 성과로 독재를 정당화하는 인물로 정리
- 누 자치의 밝은 공포를 민속·축제 이미지가 아닌 미래형 의료 복지와 친절한 통제로 차별화
- 두 인물의 과거 협력, 탈출 실패, 결별, 베타를 둘러싼 대립 설계

문서: `docs/CHARACTERS_TAU_NU.md`

### 3. 표면 7층

- F1 로비 — 카파
- F2 일반 병동 — 타우, 장기 시스템 해금
- F3 응급·회수 구역 — 시그마
- F4 진단·연구 구역 — 입실론
- F5 수술센터 — 알파
- F6 정온 구역 — 누
- F7 중앙 코어 — 오메가

각 층의 장소 콘셉트, 필수 사건, 타우·누 연결, 보스 서사 기믹, 연출 예산을 작성했습니다.

문서: `docs/SEVEN_FLOOR_STORY.md`

### 4. 세력 관계 사건표

- 타우·누·시그마·카파·알파·입실론·오메가의 대립과 의존 관계 정리
- 관계를 설명문이 아니라 이식기, 공급 계약, 출입 기록, 통증 이전, 보스 패턴으로 전달하는 사건 설계
- 반복 플레이용 핵심 서사 플래그 초안 작성

문서: `docs/FACTION_EVENT_MATRIX.md`

## 고정된 연출 방향

- 효과와 공간을 먼저 경험시키고 설명은 짧게 뒤따르게 함
- 한 장면에서 새 핵심 사실 하나만 전달
- 일반 강제 대화는 1~3문장, 약 3~7초 이내
- 두 방 연속 강제 연출 금지
- 인물의 철학을 보스 패턴과 시스템 해금으로 표현
- 첫 클리어는 큰 인과만 이해시키고 세부 관계는 반복 플레이에서 확장
