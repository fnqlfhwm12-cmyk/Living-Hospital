# 프로젝트 상태

마지막 갱신: 2026-08-02

## 현재 기준

- 저장소 기준 최신 빌드: **v0.4.0.b**
- 기준 파일: `Living_Hospital_v0.4.0.b.html`
- 주 테스트 환경: iPhone 가로 화면

## 이번 수정

1. A버튼을 이동 조작과 동시에 누를 수 있도록 터치 시작 시점에 스왑 처리
2. 좌측 상단 HUD를 하트 체력, 장기·유물, 무기 두 칸, 검체 순서로 재배치
3. 체력을 하트 3개, 총 6칸으로 변경하고 유효 피격당 반 칸 감소
4. 진행 시간과 화면 디버그 문구 숨김
5. 방문하지 않은 방은 미니맵에서 어두운 실루엣으로만 표시
6. 적 처치 검체는 구슬을 생성하지 않고 자동 회수
7. 검체 보관실 보상도 방 진입 시 자동 회수되어 필드 오브젝트를 남기지 않음

## 다음 확인 항목

- 이동 손가락을 유지한 상태에서 A버튼 스왑이 안정적으로 작동하는지
- 하트 반 칸 감소와 사망 판정이 일치하는지
- 장기·유물 네 칸이 작은 가로 화면에서 잘리지 않는지
- 미니맵의 방문·미방문 방 구분이 충분히 읽히는지
- 검체 자동 회수량이 지나치게 빠르지 않은지
